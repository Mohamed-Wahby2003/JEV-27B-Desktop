# JEV 27B Ollama

**JEV 27B Ollama** (September 27, 2026) is the local GGUF. jev ai model, jev model, typesafe jev, jev huggingface, jev llm, jev api, jev playground. `ollama run hf.co/Atlas3D/JEV-27B-VL-GGUF`. Windows 10/11 x64.

## Getting Started
1. Install Ollama 0.35.1.
2. `ollama run hf.co/Atlas3D/JEV-27B-VL-GGUF`
3. Prefer Q8_0. Q4_K_M is lossy.
4. Notes in `files/notes/`.

## FAQ

**Need patched llama.cpp?**
Full System 1 `/v1/systemone` needs the JEV patch. Plain Ollama chat is System 2.

**VRAM?**
Q8_0 ~23-34 GB. Q4_K_M ~18-23 GB.

## Requirements
Windows 10/11 x64. NVIDIA / AMD with enough VRAM. Ollama.
